# Reproducing the shipped app

`app/index.html` is a **generated file** — ~600 KB of assembled HTML that nobody
reads in a diff. That is convenient for users (one file, no server, works from a
USB stick) and awkward for a reviewer, who has to take on faith that the shipped
artifact is what the sources say it is.

It isn't faith. Reproduce it in two commands:

```bash
python3 scripts/embed_demo.py
git diff --exit-code app/index.html app/src/embedded-graph.html
```

An empty diff means the committed artifact is exactly what the sources build to.
No dependencies are needed — Python 3 standard library only, no npm, no network.

CI runs this on every push and pull request
([.github/workflows/verify.yml](../.github/workflows/verify.yml)) and additionally
asserts that the file loads no remote asset and still carries its
Content-Security-Policy. The step summary prints the artifact's SHA-256 so a
release can be pinned to a hash.

## What goes into it

| Source | Role |
|---|---|
| `app/src/shell.html` | page structure, `<head>`, CSP, three placeholders |
| `app/src/css/NN-*.css` | style partials, concatenated in filename order |
| `app/src/js/NN-*.js` | script partials, one shared scope, order matters |
| `app/src/embedded-graph.html` | the demo graph — itself generated by `embed_demo.py` from files carrying `demo: true`, plus their local avatars inlined as `data:` URIs |

`build_app.py` substitutes the three placeholders and writes the result. That is
the whole build: no minifier, no bundler, no transpiler, nothing fetched.

## Editing

Never edit `app/index.html` or `app/src/embedded-graph.html` by hand — the next
build overwrites both. Edit the partial (see [app/src/README.md](../app/src/README.md)
for the component map), then:

```bash
python3 scripts/build_app.py
```

Use `embed_demo.py` instead when demo content changed — it regenerates the
embedded graph and calls the build itself.

## Dependencies

There are none to audit:

- **No third-party JavaScript.** No framework, no charting library, no bundler
  output. Everything in `app/src/js/` is first-party code.
- **No web fonts, no CDN, no external stylesheet.** System font stack only.
- **Python standard library only** for the four scripts (`os`, `re`, `sys`,
  `json`, `base64`, `html`, `datetime`, `urllib.parse`).
- **No `package.json`, no lockfile, no `node_modules`.**

So the SBOM answer is a sentence rather than a document: the supply chain is the
repository itself plus your Python interpreter and your browser.
