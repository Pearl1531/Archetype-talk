# Idea:3 Context mode "It wasn't me" (Listening Modes)

- **When:** When I listen in a different context than usual — at a party, at the gym, or when someone else uses my account,

- **I want:** to flag the session as "a different context" with one tap, so it doesn't train my algorithm,

- **So that:** my Discover Weekly and daily recommendations stay clean and tuned to me, not to a random session.
