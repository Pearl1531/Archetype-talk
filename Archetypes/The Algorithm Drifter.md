# The Algorithm Drifter

- **Short description:** A user whose recommendation profile got “polluted” by sudden context changes. They play party playlists, put on kids' music, or share the account with a partner, so the algorithm stops understanding their real taste.

- **Link to persona:** [Emma](../Personas/Emma.md) shares her account with a partner of different taste — [Shared account with partner](../Signals/Shared%20account%20with%20partner.md) — and lost trust in Discover Weekly — [Doesn't trust Discover Weekly](../Signals/Doesn%27t%20trust%20Discover%20Weekly.md). The same pattern in parents: kids' music breaks the profile — [Kids' music pollutes profile](../Signals/Kids%27%20music%20pollutes%20profile.md).

- **Core pain:** No control over the algorithm and a need for a “Reset” / “that wasn't me” button.

- **Resists agreeing about:** "Your recommendations are pretty accurate, aren't they?" — no; they'll point straight at the specific event (a shared account, a party) that broke them, not soften it into a vague "mostly fine."
