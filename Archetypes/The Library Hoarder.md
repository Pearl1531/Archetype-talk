# The Library Hoarder

- **Short description:** Saves everything "for later" but rarely comes back. The Liked Songs library grows until it's unnavigable, while the real repertoire shrinks to a few fixed playlists. The save mechanism exists, but itself creates a new problem.

- **Link to persona:** [Emma](../Personas/Emma.md) has 2000+ liked songs and returns to the same five playlists — [Lost library](../Signals/Lost%20library.md).

- **Core pain:** Abundance without structure — "I have everything, so I have nothing." No tags, filters, or organising by mood/energy.

- **Resists agreeing about:** "Your library is well organised, right?" — no; volume isn't organisation, and they won't pretend a 2000-track dump is a working system.
