# Abandoned searches

## Content

Users report on Spotify Community that **search fails inside your own library** — you can't search all playlists from one place, so finding a track you know is "in here somewhere" ends in failure. The effect is described plainly in threads: users give up and re-add the same track/album.

## Takeaways

- Failing search within one's own collection is a moment of real frustration — the user returns to an old playlist instead of exploring.
- Search by lyric/melody fragment and searching the whole library are unmet needs.
