# Workshop Flow

Step-by-step guide for running a persona session. Each session type produces files across the five folders.

---

## Session types

### A) Create from scratch (Level 1–2)
Use when: starting a new project, little or no research yet.
1. Ask: target audience, product context, main hypothesis
2. Name the pattern → create `Archetypes/<Name>.md` (Level 1)
3. Ask for any desk research / big data → create `Evidence/` files (Level 2)
4. Draft `Personas/<Name>.md` with hypothesis-level JTBD and Pains

### B) Deepen existing persona (Level 3→4→5)
Use when: new research is available.
1. Read the existing `Personas/<Name>.md`
2. Turn transcripts/tests into `Signals/` (Level 3) — see transcript-analysis.md
3. Link the Persona's Pains/Quotes/Evidences to those files
4. Synthesise `## Correlations` from Signals + Evidence (Level 4)
5. Draft `Ideas/` addressing the pains; mark `category: Primary` (Level 5)

### C) PM update flow
Use when: a PM wants a quick update, no full workshop.
1. Read the existing Persona file
2. Show current state in summary
3. Ask what changed
4. Update only the relevant sections + their links
5. Bump metadata / review line

---

## Questions to ask at each level

**Level 1 → 2:** Do you have market reports or big data about this group? Typical age, location, device?
**Level 2 → 3:** How many interviews/tests? What surprised you? Can you share direct quotes?
**Level 3 → 4:** What patterns repeat across Signals? Where do Evidence and Signals disagree? What opportunities appear?
**Level 4 → 5:** Is this Primary or Secondary? How confident per section? Which Ideas address the top pains?

---

## Output checklist

Before finishing, confirm:

- [ ] Archetype file exists in `Archetypes/` (Level 1)
- [ ] Evidence files created for any hard data (Level 2)
- [ ] One Signal per observation in `Signals/`, each with a quote/date and `evidences:` (Level 3)
- [ ] Persona Pains / Quotes / Evidences link to the right files
- [ ] Correlations link Signals + Evidence (Level 4)
- [ ] Ideas drafted and linked; `category` set (Level 5)
- [ ] Every link URL-encodes spaces / Polish chars / parentheses
